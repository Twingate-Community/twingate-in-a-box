Trust the Twingate in a Box CA

Apps in the box are served over HTTPS with certificates from the box's own CA. Install it on the machine you browse from and every https://*.box.internal app opens without a warning.

Download the CA certificate

The commands below expect it in your Downloads folder as twingate-in-a-box-ca.pem.

macOS

sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ~/Downloads/twingate-in-a-box-ca.pem

Linux (Debian, Ubuntu)

sudo cp ~/Downloads/twingate-in-a-box-ca.pem /usr/local/share/ca-certificates/twingate-in-a-box-ca.crt
sudo update-ca-certificates

Windows, from an elevated prompt

certutil -addstore -f Root %USERPROFILE%\Downloads\twingate-in-a-box-ca.pem

Firefox keeps its own trust store. Import the file under Settings, Privacy & Security, Certificates, View Certificates, Authorities.

Restart your browser afterwards so it picks up the change.

Remove it when you are done. The CA is not limited to box.internal, so whoever holds its private key could sign a certificate for any site.

Removing it

# macOS
sudo security delete-certificate -c twingate-in-a-box-ca /Library/Keychains/System.keychain

# Linux
sudo rm /usr/local/share/ca-certificates/twingate-in-a-box-ca.crt
sudo update-ca-certificates --fresh

# Windows, from an elevated prompt
certutil -delstore Root "twingate-in-a-box-ca"
